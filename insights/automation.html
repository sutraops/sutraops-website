Learning Path 02

Automation Learning

Learn how to simplify repetitive business tasks, improve data quality and shorten process cycle times through practical Excel, scripting and workflow automation.

Explore the roadmapAll learning paths

Suggested learning roadmap

  • 01 · Identify automation opportunitiesMap the process, identify bottlenecks, measure effort and define control requirements before automating.
  • 02 · Excel foundations for operationsTables, formulas, lookup functions, conditional logic, data validation, PivotTables and error checks.
  • 03 · Advanced Excel and repeatable reportingPower Query concepts, reusable templates, reconciliation logic and standardised month-end reports.
  • 04 · VBA fundamentalsVariables, loops, conditions, procedures, workbook/sheet objects, error handling and safe macro design.
  • 05 · VBS and desktop task automationFile handling, repetitive task scripting, scheduling concepts and responsible handling of credentials.
  • 06 · Microsoft Power AutomateTriggers, actions, approvals, notifications, connectors and exception handling.
  • 07 · Finance automation projectsReconciliation support, file consolidation, journal validation, close trackers and exception reports.
  • 08 · Governance and measurementAccess controls, audit trails, testing, documentation, support ownership and hours saved.

Start with a small project

Choose one recurring task and define its current effort, inputs, expected output and failure checks.

Build a small prototype, test it with sample data, document the controls and compare the results against the manual process.

Good first project: consolidate multiple Excel files into one standardised report with validation checks.

Practical project ideas

Reconciliation helper

Compare two data sets, flag unmatched items and produce an exception list for review.

Month-end file consolidator

Combine files using a consistent format and generate a summary with source-file checks.

Workflow reminders

Notify task owners about due dates and approvals while keeping a traceable status log.
